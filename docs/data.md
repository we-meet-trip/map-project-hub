# 데이터 카드

이 문서는 map-project-hub 가 레포에 담아 배포하는 자료, 실행 중에 외부에서 받아 저장하는 자료, 그리고 각 자료의 이용 조건을 정리한다. 레포의 코드는 MIT 라이선스지만 **아래 1절의 자료는 MIT 가 아니라 각 출처의 이용 조건을 따른다.**

## 1. 레포에 포함된 제3자 자료

### 1.1 행정구역·예보 격자 대응표 (`migrations/data/region_grid_seed.sql`)

| 항목 | 내용 |
|---|---|
| 출처 | 기상청, 「기상청_단기예보 조회서비스」 참고문서의 격자 위경도 자료(공공데이터포털 데이터 ID 15084084) — <https://www.data.go.kr/data/15084084/openapi.do> |
| 이용 조건 | 공공누리 제1유형(출처표시) — 출처를 밝히면 상업적 이용과 변경이 가능하다. <https://www.kogl.or.kr> |
| 담긴 내용 | 행정구역 코드(10자리), 시도·시군구·읍면동 이름, 예보 격자 좌표(nx, ny), 대표 경도·위도 |
| 우리가 바꾼 점 | 원본 열 가운데 위 8개 열만 골라 하나의 `INSERT` 문으로 만들었다. 원본의 도·분·초 좌표 대신 소수 좌표 열을 쓴다. |
| 알려진 결함 | 강원 9개 시군구 대표 행은 생성 과정에서 칸이 하나씩 밀려 들어가 있다. 파일은 그대로 두고 마이그레이션 `008_fix_shifted_region_rows` 가 적재 뒤에 바로잡는다. |
| 한계 | 원본은 행정구역 개편에 맞춰 판이 바뀐다. 이 파일은 특정 판에서 만든 것이라 그 뒤에 생기거나 바뀐 행정구역 코드는 없다. 새 판을 넣을 때는 기존 행을 지우지 말고 별도 마이그레이션을 추가한다. |
| 적재 | 마이그레이션 `002_seed_region_grid` 가 파일을 그대로 실행한다. |

### 1.2 중기예보 구역코드 (`migrations/revisions/003_seed_subscribed_grids.py`, `007_fix_mid_land_reg_ids.py`, `009_expand_subscribed_grids.py`)

| 항목 | 내용 |
|---|---|
| 출처 | 기상청, 「기상청_중기예보 조회서비스」 참고문서의 육상·기온 예보 구역코드(공공데이터포털 데이터 ID 15059468) — <https://www.data.go.kr/data/15059468/openapi.do> |
| 이용 조건 | 공공누리 제1유형(출처표시) |
| 담긴 내용 | 시도별 중기 육상예보 구역코드와 시군구에 대응시킨 중기 기온예보 지점 코드 |
| 우리가 바꾼 점 | 공식 시군구 대응표가 없어 지점 이름과 시군구 이름을 맞춰 배정했다. 지점이 없는 광역시 자치구 등은 그 시도의 코드를 물려받는다. 강원 영동·영서 경계는 거리로 고르면 틀리므로 영동 7곳을 이름으로 정했다. |

### 1.3 예보 코드 의미표 (`map_project_hub/codes/kma_codes.py`)
하늘 상태(SKY)·강수 형태(PTY) 코드 값과 그 뜻이다. 출처는 1.1 과 같은 「기상청_단기예보 조회서비스」 오픈API 활용가이드(15084084, 공공누리 제1유형)다. 미세먼지 등급 구간(PM10 30·80·150, PM2.5 15·35·75 µg/m³ 를 경계로 좋음·보통·나쁨·매우나쁨)과 시도 정식 명칭 ↔ 대기오염 API 축약형 대응표(`map_project_hub/codes/air_codes.py`)는 사실 값을 코드로 옮긴 것이다.

## 2. 실행 중에 받는 자료 (레포에 없음)

hub 는 아래 자료를 **운영자가 발급받은 키로** 실행 중에 받아 캐시하거나 저장한다. 키가 비어 있는 공급자는 부르지 않는다. 레포에는 받은 자료가 들어 있지 않다. 각 서비스의 이용 약관은 키를 발급받는 사람이 확인하고 지켜야 한다.

| 자료 | 받는 곳 | 저장 | 비고 |
|---|---|---|---|
| 단기·초단기·중기 예보 | 기상청 (공공데이터포털) | `hub_data.short_term_forecast`·`mid_land_forecast`·`mid_temp_forecast`·`weather_nowcast_snapshots` | 구독한 격자만 주기적으로 받는다 |
| 대기오염 측정값 | 한국환경공단 에어코리아 (공공데이터포털) | `hub_data.air_quality_snapshots` | |
| 걷기·자전거 코스 | 한국관광공사 두루누비 (공공데이터포털) | `hub_data.places`(`source='durunubi'`) | 코스 GPX 에서 대표 좌표와 경계 상자만 계산해 저장 |
| 장소 검색·주소 | Kakao Local | Redis 캐시 | |
| 블로그 후기 | 네이버 검색 | Redis 캐시 | 제목·요약 문구를 표시용 마크업만 지우고 그대로 전달한다. 원문 링크를 함께 준다. |
| 장소 사진 | Google Places | Redis 캐시(사진 주소와 메타데이터) | **사진 바이트를 받거나 중계하지 않는다.** 발급처가 준 사진 주소(`photoUri`)와 저작자 표시(`authorAttributions`)만 전달하고, 화면은 저작자 표시를 함께 보여야 한다. |
| 지하철·대중교통 경로, 노선 좌표 | ODsay | Redis 캐시 | |
| 따릉이 대여소 | 서울 열린데이터광장 | Redis 캐시 | |
| 공유 킥보드 위치 | 국토교통부 퍼스널모빌리티 (공공데이터포털) | Redis 캐시 | 발급처가 사업자명을 필수로 받아 기본 사업자 목록(`HUB_PM_PROVIDERS`)을 코드에 둔다. 사업자 이름은 각 사의 상표이며 이 프로젝트와 제휴 관계가 없다 |
| 도보·자전거 경로 | OSRM (운영자가 띄운 인스턴스) | Redis 캐시 | 그래프 데이터와 그 라이선스는 OSRM 을 띄우는 쪽(map-project-infra)의 데이터 카드를 따른다 |


이 저장소의 어떤 기능도 위 서비스와 제휴하거나 보증받지 않았다. 서비스 이름은 연동 대상을 가리키기 위해서만 쓴다.

## 3. 스키마 (`hub_data`)

| 테이블 | 내용 | 채우는 주체 |
|---|---|---|
| `region_grid` | 행정구역 ↔ 예보 격자 대응(1.1) | 마이그레이션 0002, 0008 |
| `subscribed_grids` | 예보를 받아 둘 격자와 중기 구역코드(1.2), 활성 여부 | 마이그레이션 0003·0009, 관리 콘솔(`/internal/grids/*`) |
| `short_term_forecast` | 단기예보 값(격자·예보 시각·항목별) | 스케줄러 |
| `mid_land_forecast` | 중기 육상예보(구역·발표 시각·며칠 뒤·오전/오후) | 스케줄러 |
| `mid_temp_forecast` | 중기 기온예보(최저·최고와 범위) | 스케줄러 |
| `weather_nowcast_snapshots` | 초단기 실황(날짜·시각·격자별 기온·강수 형태) | 스케줄러 |
| `air_quality_snapshots` | 측정소별 미세먼지 | 스케줄러 |
| `places` | 장소·코스(좌표는 PostGIS `geometry(Point, 4326)`) | 코스 동기화 잡 |
| `forbidden_zones` | 추천에서 뺄 구역(`geometry(Polygon, 4326)`) | 관리 콘솔(`/internal/forbidden-zones/*`) |

열 단위 정의는 `migrations/revisions/` 가 기준이다.

## 4. 재생성할 수 없는 자료와 호환성
- 1.1 의 시드는 원본의 특정 판에서 만든 것이고, 같은 판을 다시 받을 수 있다는 보장이 없다. 새 판으로 바꾸면 행정구역 코드가 달라질 수 있어 구독 격자(0009)도 다시 검증해야 한다.
- 이 레포는 비공개 운영 환경의 데이터베이스 내용(적재된 예보·장소·금지 구역)을 담지 않는다. 새로 설치하면 빈 테이블에서 시작하고 스케줄러가 채운다.
