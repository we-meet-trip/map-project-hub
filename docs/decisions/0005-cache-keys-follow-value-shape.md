# 0005. 캐시 키는 담는 값의 모양을 따른다

## 맥락
대중교통 경로 후보에 필드를 더해 배포한 직후, 옛 모양으로 담긴 캐시 항목이 그대로 읽혀 500 이 났다. 한동안은 캐시 네임스페이스에 판 번호를 박고 모양이 바뀔 때마다 손으로 올렸다.

## 선택지
1. 배포할 때 캐시를 비운다.
2. 판 번호를 손으로 올린다.
3. 응답 모델 스키마에서 지문을 만들어 키에 넣는다.

## 결정
3. 경로·대중교통 경로 캐시 키에 응답 모델 스키마의 지문(sha256 앞 12자)을 넣는다. 발급처 원본을 그대로 담는 노선 좌표 캐시는 지문을 넣지 않는다. 모든 공급자 캐시 키는 끝에 `:live`/`:stub` 을 붙여 스텁 결과를 실제 응답으로 다시 내지 않는다.

## 결과
- 모델을 바꾸면 키가 저절로 바뀌고 옛 항목은 TTL 로 사라진다. 손으로 올리다 빠뜨릴 일이 없다.
- 모델의 설명 문구만 바꿔도 지문이 바뀌어 캐시가 한 번 비워진다(비용은 캐시 적중 한 번).
