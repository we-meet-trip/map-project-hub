# 0007. 제3자 콘텐츠는 링크와 출처 표시로만 전달한다

## 맥락
장소 사진(Google Places)과 블로그 후기(네이버 검색)는 저작권과 약관이 있는 제3자 콘텐츠다. hub 가 사진 바이트를 받아 다시 내주면 저장·재배포 문제가 생기고, 사진 조회 단계에는 과금이 있다.

## 선택지
1. 사진 바이트를 받아 캐시하고 중계한다.
2. 발급처가 준 사진 주소와 저작자 표시만 전달하고, 화면이 직접 불러온다.

## 결정
2. hub 는 사진 바이트를 받지 않는다. 사진 주소와 `authorAttributions` 만 넘기고, 주소는 수명이 짧아 저장하지 않는다. 하루 발급 상한(`HUB_GOOGLE_PHOTOS_DAILY_MEDIA_CAP`)을 두고 0 이면 사진 조회를 끈다. 블로그 후기는 표시용 마크업만 지운 제목·요약과 원문 링크를 전달한다. 앱은 사진을 사용자가 누를 때만 불러온다.

## 결과
- 레포와 hub 에 제3자 이미지가 쌓이지 않는다.
- 화면은 저작자 표시를 함께 보여야 한다.
- 키를 넣지 않으면 사진·후기 조회를 하지 않는다.
