# 0006. 행정구역 격자 대응은 기상청 배포 자료에서 가져온다

## 맥락
시군구·읍면동 이름과 좌표를 기상청 예보 격자(nx, ny)로 바꾸는 대응표가 필요하다. 공식 시군구↔중기 기온 지점 대응표는 없다.

## 선택지
1. 실행 때마다 좌표를 격자로 변환하고 행정구역은 다른 출처에서 받는다.
2. 기상청이 단기예보 조회서비스 참고문서로 배포하는 격자 위경도 자료를 시드로 넣는다.

## 결정
2. 그 자료(공공누리 제1유형, 출처표시)에서 8개 열을 골라 시드로 넣고, 출처와 이용조건을 파일 머리·[data.md](../data.md)·README 에 밝힌다. 중기 구역코드도 같은 방식으로 기상청 중기예보 조회서비스 자료에서 가져온다. 시드의 손상은 시드를 고치지 않고 마이그레이션으로 바로잡는다.

## 결과
- 오프라인에서도 지역 조회가 된다.
- 시드는 특정 판에서 만든 것이라 그 뒤의 행정구역 개편은 들어 있지 않다. 새 판은 별도 마이그레이션으로 더한다.
- 강원 9행의 칸 밀림은 마이그레이션 0008 이 고친다([troubleshooting.md](../troubleshooting.md) T-WEATHER-03).
