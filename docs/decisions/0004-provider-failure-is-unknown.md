# 0004. 공급자 실패는 "모른다"로 남긴다

## 맥락
키가 없거나 발급처가 실패할 때 빈 값을 성공처럼 내면, 화면은 "맑음·강수 0%·주변에 장소 없음"처럼 그럴듯한 오답을 보여 준다. 이런 오답은 오류로 보이지 않아 아무도 알아차리지 못한다.

## 선택지
1. 실패하면 고정 스텁이나 빈 성공 값으로 물러선다.
2. 실패를 상태 값(`unavailable`·`partial` 등)이나 503 으로 드러내고, 스텁은 이름으로 명시해 켤 때만 쓴다.

## 결정
2. 키가 비어 있으면 그 공급자를 부르지 않고 '조회 불가'로 답한다. 스텁은 `HUB_PLACES_STUB_MODE=true` 일 때만 쓰고, 인증을 켠 환경에서는 켤 수 없다. 불완전한 예보 페이지는 적재하지 않는다.

## 결과
- 화면이 실패를 실패로 표시할 수 있다.
- 키 없는 빠른 시작은 스텁 모드를 명시해야 한다.
- 일부 사업자만 실패한 킥보드 조회처럼 받은 만큼이라도 쓸모 있는 경우는 `partial` 로 구분한다.
